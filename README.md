# Nahda Safety & Health Website

This folder contains a professional single-page website for Nahda Safety & Health, built with Tailwind CSS and optimized for responsive performance and SEO.

## Files

- `index.html` — Main website page.
- `assets/` — High-resolution images and logo used by the website.

## Features

- Responsive layout for desktop, mobile, and tablet
- Tailwind CSS design system with modern UI/UX
- SEO-focused metadata and structured data JSON-LD
- WhatsApp quick contact link
- AI consultant section, services, projects, CEO talk, FAQ, and contact form

## Deployment to GitHub Pages

1. Create a GitHub repository named `nahdasafety` or your desired repo name.
2. Copy this entire project folder into the repository.
3. Commit and push to the `main` branch.
4. In GitHub repository settings, enable **Pages**.
   - Source: `main` branch
   - Folder: `/ (root)`
5. Save.

Your site should be available at `https://<username>.github.io/<repository>/`.

## Notes

- To update the logo, replace `assets/nahda-logo.jpeg`.
- For Arabic support, create a second HTML file or bilingual toggle with translated content.
- Verify the contact form action in `index.html` if you want a production-ready backend form instead of `mailto:`.

## Customization

- Update `<title>`, `<meta>` tags and page copy in `index.html` for content changes.
- Replace images in `assets/` with your own high-resolution visuals.
